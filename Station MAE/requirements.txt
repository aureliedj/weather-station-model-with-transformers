# History of this pin (read before changing it)
# ---------------------------------------------
# This file used to pin `torch==2.13.0+cu128`, which DOES NOT EXIST. PyTorch's
# cu128 index stops at 2.11.0+cu128 — from 2.12 onwards the builds moved to a
# newer CUDA. The pin was unsatisfiable on any index, which is why installs
# failed with the misleading "Could not find a version that satisfies".
#
# The reason a CUDA-12.8 build was wanted at all is also gone: an earlier Renku
# node had a driver that topped out below 12.8, so the default PyPI wheel failed
# CUDA init and fell back to CPU silently. As of 2026-07-31 the node reports
#     driver 580.159.04, CUDA 13.0, A100-80GB MIG 3g.20gb (19,968 MiB, 28 SMs)
# which is NEWER than the wheel needs, so the stock PyPI wheel works.
#
# ALWAYS run `python src/scripts/verify_env.py` after installing. A CUDA/driver
# mismatch does not raise — it silently trains on CPU, and you find out days later.
torch==2.13.0; sys_platform == "linux"
torch==2.13.0; sys_platform == "darwin"      # macOS: MPS/CPU, no CUDA variants
